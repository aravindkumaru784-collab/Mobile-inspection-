DoSJE Sentinel - Simple Mobile App Prototype

How to run:
1. Open index.html in Chrome/Edge/Safari.
2. Enter any email/password and press Login.
3. Follow the clickable demo flow:
   Dashboard -> Projects -> Project Details -> Smart Inspection
   -> Evidence -> AI Analysis -> Inspection Report.

This is a front-end prototype for demonstration. CCTV, GPS, AI and authentication
are simulated in the UI and are not connected to live services.
